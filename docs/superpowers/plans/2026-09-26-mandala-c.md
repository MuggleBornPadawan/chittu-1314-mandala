```clojure
(defn mirror-primitive [prim]
  (case (:type prim)
    :circle (update-in prim [:center 0] -)
    :arc (-> prim (update-in [:center 0] -)
              (update :start-angle -) (update :end-angle -))
    :polygon (update prim :points (fn [pts] (mapv (fn [[x y]] [(- x) y]) pts)))
    :line (-> prim (update-in [:from 0] -) (update-in [:to 0] -))
    :rect (update-in prim [:center 0] -)
    prim))

(defn replicate-d-n
  ([prims n] (replicate-d-n prims n nil))
  ([prims n {:keys [mirror?] }]
   (let [step (/ (* 2.0 Math/PI) (double n))]
     (mapcat (fn [i]
               (let [rot (* i step)
                     base (mapv #(rotate-primitive % rot) prims)]
                 (if mirror?
                   (concat base (mapv mirror-primitive base))
                   base)))
             (range n)))))
```

Call sites in `generate` pass `{:mirror? true}` for motif layers only, not backgrounds.

```clojure
(defn- lace-sector-motifs [inner-r outer-r sector-angle symmetry-order palette-hex]
  (let [mid-r (/ (+ inner-r outer-r) 2.0)
        col-gold (get pigment-hex-map :gold-leaf)
        col-white (get pigment-hex-map :conch-white)
        col-black (get pigment-hex-map :lampblack)
        pearl {:type :circle :center (polar->cart mid-r (/ sector-angle 2.0))
               :radius 0.006 :fill col-white :stroke col-black :stroke-width 0.001}
        d 0.012
        c (polar->cart mid-r 0.0)
        [pcx pcy] c
        diamond {:type :polygon
                 :points [[pcx (- pcy d)] [(+ pcx d) pcy] [pcx (+ pcy d)] [(- pcx d) pcy]]
                 :fill col-gold :stroke col-black :stroke-width 0.001}]
    (vec (replicate-d-n [pearl diamond] symmetry-order))))
```
